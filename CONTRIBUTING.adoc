= Contributing

Contributions are always welcome!
And there is a multitude of ways in which you can help depending on what you like to do, or are good at.
Anything from documentation, code cleanup, issue completion, new features, you name it, even filing issues is contributing and greatly appreciated!

== Conduct

This project adheres to our link:CODE_OF_CONDUCT.md[Code of Conduct]. This describes the minimum behavior expected from all contributors.

== Developer Certificate of Origin

All commits must be signed off to affirm compliance with the link:https://developercertificate.org/[DCO].

== Setup pre-commit hooks

This repository uses prek for pre-commit hooks.

Run `prek install` while in the devcontainer to setup the hooks locally.

== Check your changes

Before creating a merge request, please run `tools/check-merge-request.sh` to validate your changes.
