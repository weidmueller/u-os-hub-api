## Mock HTTP API

The Mock HTTP API provides a mock backend which can be used to test the Swagger UI.

## Installation

```bash
$ npm ci
```

## Running the app

You can run the Mock HTTP API in one of two ways:

- Directly from the terminal using the following commands:

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

- Using the launch configuration in VSCode in 'Run and debug'.
